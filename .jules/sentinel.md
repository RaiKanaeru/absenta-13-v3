## 2026-06-16 - Improve SQL Blocklist validation\n**Vulnerability:** Weak SQL blocklist validation in `server/controllers/databaseFileController.js` using string `.includes()`.\n**Learning:** This could be bypassed using spaces, tabs, or newlines, like `DROP    TABLE`.\n**Prevention:** Replace naive string `.includes()` with robust regular expressions utilizing `\s+` to catch varied spacing.
